## 0:40 — Create, rename, save, reload

- Click **+ New doc**.
- Click the title field in the top bar, rename it to "Team notes", press Enter — the pill shows **Saved**.
- In the editor: make some text bold and italic, add an H2 heading, then a bullet list and a numbered
  list. Watch the pill flip **Saving… → Saved**.
- Refresh the browser. Reopen **Team notes** — text and formatting survived (persistence proved).

## 1:55 — Import a Markdown file

- Click **Import** → choose `demo.md`:
  ```md
  # Roadmap
  - Add realtime collaboration
  - Add a viewer role
  ```
- Confirm the new doc is under **Owned by me** as `demo`, opens immediately, and renders the H1 and
  bullet list.

## 2:20 — Sharing (the key flow)

- While signed in as saan: open **Team notes** → click **Share** → type `reviewer@ajaia.local` →
  **Share**. A success toast appears; the reviewer now shows in "People with access".
- Open the user menu → **Switch user / sign out** → sign in as **reviewer@ajaia.local**.
- **Team notes** now appears under **Shared with me** with an **Editor** badge.
- Edit a line as the editor → **Saved**.
- Try to rename the document → a toast explains **"Only the owner can rename"**.
- Now sign in as **teammate@ajaia.local**: **Team notes** is absent from the sidebar, and opening the
  doc's URL shows **"Document not found"** toast (graceful access stall).
